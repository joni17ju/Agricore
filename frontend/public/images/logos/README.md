# Institutional logos

Drop the two logo files here with exactly these names:

- `dorsu-logo.png` — Davao Oriental State University
- `bsagri-logo.png` — BS Agriculture department

They appear automatically in the round spots on the landing page header, the
sign-in / register / password-reset screens and the sidebar. Square PNGs of
about 192 × 192 px with a transparent or white background work best (they are
shown at 40–48 px inside a circle). Until a file exists its spot stays an empty
outlined circle.
